# Ai Hot Digest

> 每晚聚合 AI 热点（新闻/模型/MCP/Skills/套餐）并推送微信的 OpenClaw skill。Daily AI hot news aggregation with LLM summary and WeChat push.

## 安装

将本仓库放到 OpenClaw 技能目录即可使用：

```bash
git clone <本仓库地址> ~/.openclaw/workspace/skills/ai-hot-digest-skill
# 或放入 ~/.openclaw/skills/
```

## 配置

如需 API Key、邮箱授权码等配置，请参考 `SKILL.md` 中的说明，通过环境变量或本地 `.env` 文件设置（**不要提交到仓库**）。
